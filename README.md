# PD Warriors 2027 Document Verification

Standalone document-verification website for Parkinson's Disease Warriors Philippines — Get Together 2027.

First working static build includes attendee search, verification status dashboard, document requirements, upload selection, verify/reject workflow, authorized representative fields, offline-friendly local metadata, and responsive mobile/desktop layout.

> Privacy note: this GitHub Pages build does not upload sensitive identity documents to GitHub. A protected authenticated backend is required before centralized document storage is enabled.
